# ShopHoa demo

Public, browser-only preview: https://leekunda13.github.io/shophoa-demo/

Contains compiled demo assets only. Orders and admin edits are local to each browser. Email previews and payments are simulated; no SMTP, bank secrets, real customer records or production backend are published here.

The demo login is an interaction preview, not security for real data. Production uses database sessions and separately provisioned credentials. Full source and production configuration belong in the private source repository.
